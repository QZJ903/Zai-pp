# Zai++ 2.15.50

> 本版把「注入的那段工具结果会被用户看见」这件事处理完：**输入框里不再显示它**
> （注入期间遮住 + 提交后清掉），**切走会话再回来也不再留空白气泡**。

## 修复

### 注入的工具结果会出现在输入框里

**症状**：续跑 / nudge 的 prompt 是扩展拼好、写进输入框、再让页面自己发出去的。
那段正文是一大段工具结果 JSON，用户会在输入框里看见它。

**改法分两层**：

1. **注入期间遮住**（`maskComposerForInjection`）—— 给输入框叠一层只改外观的遮罩：
   文字透明（`color` / `-webkit-text-fill-color` / `caret-color`）＋ **把高度冻住**。
   ⚠️ **不能干脆把那段值清掉**：页面的 `bind:value` 有一条反向同步（状态 → DOM），
   实测把值静默清掉之后，下一次刷新又会把它**原样写回来**——「状态里有、DOM 里没有」
   这个状态维持不住。所以那段文本必须留在 DOM 里，只能让它看不见。
   ⚠️ **高度也要冻**：注入的是几 KB 文本，不冻的话输入框会从 40px 撑到 160px，
   那一跳同样看得见（实测读数）。
   ⚠️ 撤销挂 `finally` 兜底，并且**在把输入框交还给用户之前再撤一次** ——
   之后还有一段证据等待，遮罩留着会让用户打的字看不见。

2. **提交之后清掉** —— 提交已触发即清空，失败出口也各清一次。
   实测页面是在提交事件里**同步**读走值的，所以提前清空会把这一发打空；
   点按钮那条兜底路成功时不清（它的读值时序没有实测过）。

**成功判据同步换掉**：「输入框被页面清空」原本兼任「发送成功」的判据，自己清空之后它恒真
⇒ 改成两条：**请求计数**（主判据）＋**等待期间看到过 Stop 按钮**（副判据，只记录、
不决定什么时候返回）。副判据只在主判据没响时用来区分「其实已经发出去了」与「真没发出去」。

### 重取历史之后会留一只空白气泡

**症状**：页面从 `messages/batch` 重渲染会话时（**切走会话再切回来就会发生，不必刷新**），
续跑消息的正文已经被历史清洗换成了不可见占位符，而气泡隐藏的判据只认「模板结构标签」
⇒ 认不出来、也就没隐藏 —— 页面上留下一只**空白气泡**（实测与正常消息一样占 80px 高）。

**改法**：隐藏判据补上「文本里含占位符」这一支。⚠️ 用**含**、不用**整段相等** ——
气泡文本带着页面自己的 chrome（实测 14 个空白字符），严格判据眼下恰好也能命中，
但只要 chrome 哪天变成可见文字，它就会**静默漏判**。

### 续跑请求的探测判据

`parseZaiBody` 失败意味着**增广也会被跳过、请求按原样发出去**，那一轮仍然是正常发出的。
原判据在那种情况下认不出来 ⇒「已经发出去」被判成「没发出去」⇒ 调用方把同一段 prompt
再发一遍。现在解析那条路认不出来时**退回原文粗判**（模板的结构标签在 body 那个 JSON 串里
是字面量）。

## 评审收口

- **遮罩的还原改成「只撤当前值仍是我们写的那一份」** —— 遮罩窗口里页面自己改过的内联值
  （切主题改颜色、自动增高改高度）不再被我们覆回旧值。
- **遮罩改成「先把撤销建好、再写样式」**，写样式失败时先还原并吞掉错误 ——
  纯外观的失败不再可能留下永久透明的输入框，也不会连累发送。
- **修正 `sendPromptPrimitive` 的文档注释**：它只服务续跑链的点按钮兜底，判据也已换成「发送证据」。
- **补一条守卫**：那处「交还用户之前提前撤销遮罩」必须在无条件路径上。

## 说明

- ⚠️ **本版仍需真机验收**，三条见下。
- 构建流程与沙箱注意事项见项目记忆里的构建说明。

## 验收

① **带工具的自动化任务** —— 续跑注入那一刻，**输入框里看不见那段工具结果**
   （既不该显示出来，也不该把框撑高）；续跑照常推进多轮，任务状态正常收尾。

② **同一会话切走再切回来**（或刷新页面）—— 之前会出现空白气泡，本版应消失。
   读数：在会话页 Console 里跑
   `[...document.querySelectorAll('.user-message')].filter((el) => /\p{Cf}/u.test(el.textContent ?? ''))`
   凡命中者（正文含不可见格式字符的那几条）现在都应带
   `data-dpp-hidden-continuation="true"`、且 `getBoundingClientRect().height` 为 0。

③ **没有重复的用户消息** —— 整个任务跑完，会话里不应出现重复的续跑消息。
