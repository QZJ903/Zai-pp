# Zai++ 2.15.55

> 本版**没有任何新功能**，只做三件事：把仓库里残留的旧代号清干净、删掉五个已无消费者的死代码、
> 修两处「出错时会把界面留在坏状态」的结构性问题。**升级后需要重装 Shell Native Host。**

## 需要你做一件事：重装 Shell Native Host

Native Host 的注册名从 `com.glm_pp.shell` 改成了 `com.zai_pp.shell`，安装目录与 Windows 注册表键
也一并换了。**旧的那份装在那儿也不会被认**，请在 MCP 页的 Shell 服务里重新执行一次安装命令
（页面会带上当前扩展 ID），然后重启浏览器。

本版**不会迁移旧数据**：本扩展此前从未公开发布，直接换标识不涉及用户数据。若你本地装过旧版，
升级后侧边栏的 MCP 服务、自动化任务、保存项、记忆等会是**空的新库**，旧的仍在磁盘上但读不到。

## 清理：全仓库去旧代号

`shel` / `dpp` 两代旧代号从协议层到界面层统一换成本项目的名字：

| 层 | 改了什么 |
|---|---|
| **协议与跨进程身份** | Native Host 名、MCP 传输协议名、MCP 能力注解键、包名与产物 zip 名 |
| **本机存储** | 22 个 `chrome.storage` key、两个 IndexedDB 库名、定时唤醒的 alarm 名 |
| **注入页面的 UI** | 主题 CSS 变量、背景层元素与属性、工具面板 / 项目面板 / 技能补全的类名与 `data-*` 属性 |
| **对话历史** | 我们自己注入的「用户原文」标记（刷新后靠它把增广文本还原成你真正打的那句话） |
| **内部标识** | 一批会话 / 站点层标识符、MCP 握手上报的客户端名、两个环境变量 |

⚠️ **注入页面的类名与属性也改了** —— 升级后请**刷新一次 z.ai 页面**，否则页面上旧的一组面板
会留在原地（点它没反应），新一轮又会叠一份新的。

**刻意没动的**：用量统计里的两个来源标记、模型名与模型 id（`glm-5.3` / `GLM-5.3-Flash` 这类是真实模型名）、
以及匹配站点默认标题的那条正则（它匹配的是页面标题本身）。

## 删除：五个已无消费者的死件

`clearZaiAuthFromStorage`（登录态清理，从来没被接上过）、`continuationMarkerCount`（模块级计数器，零读写）、
`dispatchEnterKey`（合成 Enter 的旧实现，已被 `form.requestSubmit()` 取代）、
`createXmlToolCallRegex`（一条曾导致灾难性回溯的正则，零生产消费者，留着容易被误用）、
以及工具面板控制器的 `requeueAll` 对外方法（对外导出但无人调用，实现保留为内部使用）。

## 修复

### 注入时若中途出错，输入框会永久禁用

续跑 / 自动化的两条发送路径都会在注入期间临时锁住输入框。原先只在**正常出口**解锁，
一旦中途抛错（写入失败、等发送按钮期间异常），输入框会**一直停在禁用态**，只能刷新页面。
现在把解锁放进 `finally`，任何出口都会还原。

### 懒建授权时没有带上 Skill 目录

「这一轮的请求增广没建成授权、工具却仍被调用」这条罕见路径会现场补建一个授权，
但**没带本轮的 Skill 目录** ⇒ 本地 Skill 的 cwd 约束对它不生效，模型给的命令可以跑到 Skill 目录外面。
现在补上了（该轮的目录不存在时仍然放行，行为与之前一致）。

### 关掉 MCP 服务后，状态仍显示「已连接」

缓存里记的是「上一次发现成不成功」，而**开关一个服务不会清这份缓存**（缓存指纹只看连接相关字段）。
于是关掉之后：状态徽章还是绿的「已连接」、提示语还是「已连接，发现 12 个工具」，
而实际上这个服务的工具一个都不会被提供。

现在一律以「此刻是否启用」为准：关掉就显示「已停用」／「服务已创建但尚未启用」，
提示区也不再折叠（否则那句话藏在折叠区里看不见）。

### Shell 服务的「自动执行」默认开启

新装的 Shell 服务以前默认关着「自动执行」，而它一关，工具列表整列显示 `0/N`、一个工具都用不了，
面板上却**没有任何一处解释是这一项在挡**。Shell 是本项目的一等能力（提示词与内置技能都按它写），
默认值改成「能用」。

⚠️ **已经装过的服务不受影响** —— 默认值只对新建的生效。你手动打开一次开关即可。

## 验收

① **Shell 服务能连上**：MCP 页 → Shell → 重新执行安装命令 → 重启浏览器 → 点「测试」，显示「已连接」。

② **页面 UI 正常**：刷新 z.ai 页面后，工具调用面板、项目面板、`/` 技能补全都能正常出现；
主题（深色 / 浅色）跟随页面正确。

③ **输入框不会被锁死**：跑一次自动化任务，中途不要手动干预，结束后输入框可以正常打字。

④ **本地 Skill 的 cwd 生效**：激活一个本地 Skill 后让它执行 shell 命令，命令在 Skill 目录下运行。

⑤ **关掉服务会变「已停用」**：把 Shell 服务的开关关掉，状态徽章应变灰、提示区显示
「服务已创建但尚未启用」，不再是绿色的「已连接」。

⑥ **自动执行默认开着**：新建一个 Shell 服务（或删掉重装），工具列表那行应显示
`3/12 自动`（默认白名单三个工具）而不是 `0/12`。
