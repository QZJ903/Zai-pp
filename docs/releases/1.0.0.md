# Zai++ 1.0.0

首个公开版本。

Zai++ 是面向 [z.ai](https://chat.z.ai) 网页版的浏览器扩展（Chrome / Edge，Manifest V3）。它不改动 z.ai 的回答本身，而是给网页补上五类能力：本机工具执行、MCP 服务接入、跨对话长期记忆、浏览器控制、定时自动化。

扩展只做编排与呈现 —— 真正执行本机命令的是一个独立的 Native Messaging 进程（Shell Native Host），跑在你自己的机器上，与网页、与扩展后台都不共享进程。记忆、Skill、保存项、自动化任务、MCP 配置全部存在浏览器本地，不经过任何中转服务器。

完整功能说明见 [README](../../README.md)。

## 安装

需要 Node.js ≥ 18.17。

### 一、构建扩展

```bash
git clone https://github.com/QZJ903/Zai-pp.git
cd Zai-pp
npm install
npm run build
```

### 二、加载扩展

Chrome 打开 `chrome://extensions/`，开启开发者模式，点「加载已解压的扩展程序」，选 `dist/chrome-mv3/`。Edge 打开 `edge://extensions/`，开启开发人员模式，点「加载解压缩的扩展」，选 `dist/edge-mv3/`。

> ⚠️ **加载后不要移动解压目录。** 未上架的扩展，ID 由安装路径算出 —— 目录一变 ID 就变，已装好的 Shell Host 会失去授权，本机工具全部失效。真要挪，挪完按下一步重装一次 host。

### 三、安装 Shell Native Host

**不做这一步，本机工具全部用不了**；记忆、Skill、MCP、自动化不受影响。

侧边栏 → **能力** → **MCP** 页会给出可复制的命令，扩展 ID 已自动填好：

```bash
npx --yes zai-pp-shell-host install --browser <chrome|edge> --extension-id <你的扩展 ID>
```

装完重启浏览器。

### 四、确认装好了

打开 [z.ai](https://chat.z.ai)，点扩展图标打开侧边栏，进 **能力 → MCP**，点「测试」。连上后应显示发现 12 个工具。

再在对话里试一句：`用 shell_exec 看一下当前目录`。模型输出工具标签、执行、把结果带回对话，说明整条链通了。

## 已知限制

- **仅支持 Chrome / Edge**。
- **浏览器控制与后台保活会显示调试横幅** —— 两者都依赖 Chrome 的调试会话，窗口顶部会出现「Zai++ started debugging this browser」，属浏览器既定行为。
- **后台保活默认关闭** —— 它解决的是「z.ai 标签在后台被节流导致任务静默失败」，不需要时可以不开。
- **需要本机安装 Node.js** —— 仅 Shell Native Host 需要；不用本机工具的话，其余功能不依赖它。

## 权限说明

- `nativeMessaging` —— 与 Shell Native Host 通信，本机工具的前提
- `debugger` —— 浏览器控制与后台保活
- `tabs` / `sidePanel` / `storage` / `alarms` —— 标签页定位、侧边栏、本地存储、定时任务
- 站点访问权限覆盖 `chat.z.ai` 与 `zchat.z.ai`，以及全部 `http` / `https` 地址 —— 后者用于连接你自己配置的 MCP 服务、从 GitHub 导入技能

所有数据存于浏览器本地，扩展不上传任何内容。
