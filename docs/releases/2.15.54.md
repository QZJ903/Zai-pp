# Zai++ 2.15.54

> 本版把 **MCP 页的工具列表改成给人看的样子**（中文名 + 一句话说明 + 风险徽章，不再是英文 schema
> 与带随机 UUID 的调用名），修掉一个**真机撞到的缓存缺陷**（改任何一项 MCP 配置都会把已发现的工具清空），
> 把续跑「这一发到底发出去没有」的判据从布尔改成三态，并把侧边栏那份**从上游搬来的更新日志**
> 换成 Zai++ 自己的首发导览。

## MCP 页：工具卡片改人话

面板上原来直接渲染描述符的 `title` / `description` / `inputSchema` —— 那是**喂模型的英文 schema**
（刻意保持英文），再加上 `mcp_<serverId>_<tool>` 这种**含每次安装随机生成的 UUID** 的调用名
和一串参数键名。现在投影成 `{ 名称, 一句话说明, 风险 }` 三项：

- **12 个内置 Shell 工具**有中文名与中文说明（如「执行 Shell 命令」「写入文本文件」）；
- **第三方 MCP 工具**没有中文表，回落服务端自己给的文案；
- **风险徽章三档**（只读 / 写入 / 执行）**手工逐个判过**，不从 `annotations.risk` 派生 ——
  host 把「改一个文件」和「跑任意命令」都标成 `high`，按它一刀切会正好抹掉用户最需要分辨的差别。

⚠️ **只影响显示，不动描述符本身** —— schema 必须保持英文。

顺带：Python 环境检查现在在工具列表里有一张正常卡片，不再需要一个单独的「可用」徽章。

## 修复：改一项 MCP 配置就把工具列表清空

**症状**：在 MCP 页里**关掉任意一个工具**（或改个显示名），服务状态就从「已连接」变成「未知」、
「发现工具」从 12 变 0、延迟与上次连接都变成 `-`，必须手动点一次「刷新工具」才恢复。

**根因**：判断「配置有没有变、缓存要不要清」用的指纹是裸 `JSON.stringify`，**对对象键序敏感**。
写配置时按源码声明序重建 `timeouts`，而 `chrome.storage` 读回来是**键名字母序** ——
同一个值、两种键序 ⇒ 指纹不等 ⇒ 每次写入都被判成「配置变了」⇒ 清缓存。

**改法**：指纹外面铺一层递归的键序归一。**数组不排序**（请求头与 transport 参数有顺序语义）。

## 续跑：「这一发发出去了没有」改成三态

原来是布尔判据：请求计数涨了、或 5 秒内看到过 Stop，就算已发出。真机实测四轮样本后发现
**Stop 比请求早 3–5 毫秒出现、存活 5–7 秒** —— 页面点了发送会先渲染生成中的占位，那个占位里就有 Stop
⇒ 这条副判据被页面自己的 UI 反应点亮，**命中率接近 100%**，等于没判。

现在分三档：

- `sent`（已发出）—— 请求计数或续跑计数任一增长；
- `unsent`（未发出）—— 提交动作本身失败（没有输入框 / 页面不是空闲 / 找不到发送按钮 / 提交抛错）；
- `ambiguous`（可能已发出）—— 两个计数都没动。

**`ambiguous` 不重发**（重发就是双发），改为起一个 5 秒看门狗收尾；**也不清空输入框**
（可能已经发出去了，清了这一发就打空）。只有 `unsent` 才走兜底重发、才清输入框。

⚠️ 看门狗的收尾令牌从「步骤计数」扩成「步骤计数 + 催促计数」—— 催促轮不推进步骤计数，
旧令牌对连续两次催促不成立，会让第一次那个定时器误收正在进行的循环。

## 侧边栏：更新日志换成首发导览

那份弹层是从上游原样搬过来的，内容和实现只差几处改名 —— 首发用户打开侧边栏看到的是
**上游那一版的发布说明**，其中「浏览器控制只向新会话提供工具」一句**在本项目不成立**
（启用后所有会话都看得到）。

现在改成 6 条功能导览：记忆 / Skill / MCP / 浏览器控制 / 自动化 / 项目。
**标题与「每版都弹」的机制都没动** —— 只换内容。

## 界面文案

MCP 页的服务状态四档改成中文（已连接 / 出错 / 已停用 / 未知），空状态补上「点刷新工具重新发现」的指引；
自动化失败多一档「这一轮续跑没能确认发出（可能已发出），已停止等待」的提示。

## 验收

① **MCP 页工具列表**：每行是中文名 + 一句话说明 + 右侧风险徽章（只读 / 写入 / 执行），
   不再是英文标题与参数键名。

② **关掉一个工具之后**：状态仍是「已连接」、「发现工具」数量不变、延迟与上次连接仍在 ——
   **不需要**再点「刷新工具」。

③ **正常续跑轮不触发看门狗**：跑一个会触发续跑的自动化任务，任务照常推进到结束，
   不出现「没能确认发出」的失败。

④ **侧边栏首次打开**：弹出「版本更新内容」，里面是 6 条功能导览，点「知道了」后关闭，
   浏览器工具栏的 `NEW` 徽章消失。
