# Zai++ 2.15.46

> 修**跨站会话跳转失败**：在国际站的页面上点一条**国区站**的会话时，链接被拼到了
> 当前站，而那一站没有这条会话（两个站各有一份会话，同一条会话只存在于它自己那一站）。

## 修复

**跳转目标原本按「与当前页同源」判。** 页内项目面板与侧边栏项目页都走这个口径；
而这是错的 —— 一条国区站的会话在国际站的页面上点开时，被拼成当前站的 `/c/<id>`，
点开是空白或 404。

改为按**站点集合**判：记录里存的 URL 只要属于本站点集合（国区站或国际站），
就照它跳（**换站**）；只有它缺失、或不属于这两个站时，才按会话 id 拼到兜底站。

**判定与拼链接收成一个入口**（`resolveZaiConversationUrl`），页面内项目面板与侧边栏
项目页共用 —— 两处各判一遍正是这个缺陷的来源。项目面板的导航另抽成可注入的
`navigateToZaiConversation`（内容脚本不能被测试 import，抽出来才有行为断言）。

顺带保住原有的安全判据：存储里的 URL 可能来自同步快照导入（存储层只要求它是字符串），
所以非站点集合的值一律不导航过去 —— `javascript:` 与伪装的同域子站
（`chat.z.ai.evil.test`）都在这一步被拒。

## 说明

- ⚠️ **本版仍未跑真机验收。** 两站适配（含本次修复）的验收点见
  `Zai++2.15.45-真机验收清单.md`；本次修复对应其中「项目面板 / 会话链接」那几条，
  并新增一条：**在国际站的项目面板里点一条国区站的会话，应当跳到国区站**。
- 构建流程与沙箱注意事项见项目记忆里的构建说明。
