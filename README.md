# Zai++

> 把 [z.ai](https://chat.z.ai) 网页版扩展成一个能调用本机工具、连接 MCP、记住上下文、按计划执行任务的 AI agent 工作台。

## 产品定位

Zai++ 是面向 [z.ai](https://chat.z.ai) 网页版的浏览器扩展（Chrome / Edge，Manifest V3）。它不改动 z.ai 的回答本身，而是给网页补上五类核心能力：**本机工具执行**、**MCP 服务接入**、**跨对话长期记忆**、**浏览器控制**、**定时自动化**。

扩展本身只做编排与呈现。真正执行本机命令的是一个独立的 Native Messaging 进程（Shell Native Host），它跑在用户自己的机器上，与网页、与扩展的后台都不共享进程。

**本地优先**：记忆、Skill、保存项、自动化任务、MCP 配置都只存在浏览器本地（记忆在 IndexedDB，其余在扩展存储），不经过任何中转服务器。本机工具的输出只在你自己的机器上产生和消费。

**支持的站点**：`chat.z.ai`（国际站）与 `zchat.z.ai`（国区站）。两站各有独立的登录态，扩展分别缓存，互不干扰。

## 功能速览

| AI agent 工作台 / browser extension | 把 z.ai 网页版扩展成可以调用本机工具、复用记忆、调度自动化的浏览器内工作台。 |

| 中英双语 | 侧边栏、工具说明与内置 Skill 行为跟随所选语言，用户自己的内容不受影响。 |

## 核心功能

### 本机工具

由 Shell Native Host 提供的 12 个工具：

| 工具 | 用途 |
|---|---|
| `shell_exec` | 执行一次性 shell 命令 |
| `shell_session_begin` / `shell_session_exec` / `shell_session_end` | 持久 shell 会话：保留工作目录、环境变量与进程状态 |
| `python_exec` | 执行短 Python 片段（本机真解释器，非浏览器沙箱） |
| `python_status` | 查询本机 Python 解释器状态 |
| `local_file_read` / `local_file_write` / `local_file_stat` | 读写本地文件 |
| `local_folder_pick` | 弹出系统文件夹选择框 |
| `local_skill_preview` | 预览本地 Skill 文件夹（扩展内部使用） |

- **结果回到对话里** —— 工具输出被带回同一轮对话继续生成，不需要手动复制粘贴。
- **长文件分段读** —— 超出单次读取上限的大文件由扩展按 Unicode 码点确定性续读，不会中途静默截断。
- **失败可见** —— 每个失败都带结构化错误码，界面给出可操作的说明，而不是一句「执行失败」。
- **输出有上限** —— 单次 stdout 截断，避免一次调用把上下文撑爆。

### MCP 工具系统

在侧边栏连接任意 MCP 服务，把它的工具变成模型可调用的能力。

- **四种传输** —— stdio（本机命令）、HTTP、SSE，以及 Shell Native Host 这条内置通道。
- **发现与缓存** —— 按服务缓存工具清单，只有配置变了才重新发现。
- **执行策略** —— 每个服务可单独设为自动执行、需要确认、或禁用。
- **工具级开关** —— 逐个工具勾选，模型看到的目录随之收窄。
- **Prompt 暴露策略** —— 三档：直接（展示全部工具 schema）、自适应（只展示相关工具，可按置顶加权）、按需（schema 不进提示词，模型先发现再调用）。
- **自适应预算** —— 所有自适应服务共享一个直接展示 schema 的上限，可按工具数与字节数两个维度设定。
- **置顶** —— 给工具加权，保证它在自适应模式下不被刷掉。
- **调用历史** —— 每个服务最近调用的工具与结果，可直接翻看。
- **错误翻译** —— 服务端原始英文错误会翻成可操作的中文提示（401/403、连不上、超时、响应过大等）。

### 长期记忆

- **自动积累** —— 对话里值得长期保留的偏好、反馈、背景、参考资料会被写成条目。
- **按相关性注入** —— 每轮按关键词、置顶权重、访问频率筛选，只把相关内容放进上下文。
- **整块预算** —— 注入总长度有 token 上限，单条也有字符上限，超出按分数取前若干条。
- **可编辑** —— 新增、编辑、置顶、删除、按分类筛选。
- **导入导出** —— 备份成 JSON 或从备份恢复，导入前逐条校验格式与长度。

### Skill

- **内置两个** —— `shell`（本机命令与文件操作规范）与 `memory`（记忆读写规范）。
- **自定义** —— 直接在侧边栏写名字、描述、指令；名字会归一化成可调用的 slug。
- **从 GitHub 导入** —— 支持仓库、目录或单个 `SKILL.md` 链接，导入前先预览，不覆盖本地自定义 Skill。
- **从本地文件夹导入** —— 通过本机工具读取本地 Skill 目录，导入时不执行任何脚本。
- **自动激活** —— 可开启「按对话内容自动匹配并激活」；关闭时只有显式输入 `/技能名` 才生效。
- **斜杠补全** —— 输入框里敲 `/` 会弹出技能候选，方向键选择、回车确认。

### 浏览器控制

让模型操作你自己选定的标签页 —— 基于 Chrome DevTools Protocol 与无障碍树。

- **18 个工具** —— 导航、前进后退、刷新、标签页列举与切换、关标签、快照、点击、悬停、填表、整表填充、按键、输入、上传文件、等待条件、处理弹窗、执行脚本。
- **按无障碍树定位** —— 用快照里的节点编号操作元素，比 CSS 选择器稳定；快照文本有字节预算，避免一次塞满上下文。
- **显式启用** —— 默认关闭；开启后需要手动选择受控标签页，随时可断开。
- **z.ai 自己的标签页不可作为目标** —— 那条标签的调试会话归后台保活所有。
- **动作有超时与结果上限** —— 每个工具声明了自己的超时和最大结果字节数。

### 自动化

把固定任务交给独立会话，手动触发或按计划执行。

- **触发方式** —— 手动、Cron 五字段表达式、或 RRULE（`MINUTELY` / `HOURLY` / `DAILY` + 间隔）。
- **最小间隔 15 分钟** —— 更密的排期会被直接拒绝，而不是静默跳过。
- **固定会话** —— 可以让每次运行都落在同一会话，也可以每次新建。
- **仅本次生效的模型选择** —— 表单里选的模型只影响这一次运行，不改变会话已有的模型。
- **运行记录** —— 每次运行的状态、耗时与失败原因；失败按错误码分档给出可操作提示。
- **暂停不等于取消** —— 暂停只停排期，正在跑的那一次跑完为止。

### 两套工具，两条通道

z.ai 自带一组服务端沙箱工具，Zai++ 另加一组本机工具。两套作用域不同，可以串起来用。

| 工具 | 在哪里跑 | 能做什么 |
|---|---|---|
| 服务端沙箱工具 | z.ai 的服务端 | 做计算、格式转换、生成草稿，产出文档与图表 |
| 本机工具 | 你自己的电脑 | 读写本机文件、执行本机命令、访问桌面与项目目录 |

- **沙箱做中间处理，本机落成品** —— 先在沙箱里生成或加工，再用 `local_file_write` 把文本写到你的桌面；图片、zip、pdf 这类二进制先在沙箱转成 base64，再用 `shell_exec` 解码写盘。
- **反过来也成立** —— 本机文件要分析，先用 `local_file_read` 读出来，再交给沙箱工具处理。
- **两套的路径不通用** —— 本机路径（`C:/`、`D:/`、桌面）不能传给沙箱工具，沙箱路径（`/home/z/my-project/…`）不能传给本机工具。

### 续跑与自动纠错

工具执行完，回答本该继续往下走。但 z.ai 的页面在工具结果回填之后**不会自己继续** —— 是扩展把结果注回输入框、让页面发下一轮。这条链叫续跑。

- **自动续跑** —— 一轮里只要调用过 MCP / 本机 / 浏览器这类工具，扩展就会接上下一轮，最多 25 步。
- **待办检测（nudge）** —— 模型说完「接下来我会…」却停下来时，扩展识别出这是待办没收口，自动催一轮（最多 8 次）。判据按**主语**分档：「我来做 X」是强信号、无条件催；「接下来你可以…」是建议、不催。
- **误用纠错** —— 模型把本机工具写进原生 `tool_call` 时，那一轮什么都不会执行。扩展识别出这种误用，自动发一轮纠错，带上该工具真实参数结构的示例，要求它改用 XML 标签重发。
- **切会话即收尾** —— 切走会话时续跑循环立即收掉，不会把结果打进另一个对话。
- **失败如实上报** —— 任何一轮没跑完都会明确回传失败原因，而不是悄悄显示成功。

### 后台保活

浏览器的后台标签会被节流：定时器从毫秒级降到每秒一次，隐藏满五分钟后再降到每分钟一次。而续跑链里有几条几十到几百毫秒的等待（等输入框就绪、等发送按钮可用、等发送证据），一旦被压到秒级就会全部超时，表现为「任务静默失败」。

- **做什么** —— 通过 Chrome DevTools Protocol 给目标标签发两条命令：模拟页面获得焦点、把页面生命周期钉在 `active`。标签自报在前台，定时器就不再被压。
- **什么时候做** —— 默认只在**发送那几秒**挂上，用完立刻卸；循环跑超过 **3 分钟**才转成常驻，直到循环结束。
- **默认关闭** —— 因为它会让 Chrome 在窗口顶部显示「Zai++ started debugging this browser」横幅。长跑任务建议开启，无关场景不需要。

### 提示词

- **系统提示词预设** —— 给新对话准备固定的角色或行为边界，激活后在首条消息前自动注入；同一时间只能激活一个，可从文件导入或导出。
- **记忆注入开关** —— 关掉后新请求不再带长期记忆。
- **系统提示词开关** —— 关掉后不再注入工具 schema、记忆规则与运行时指引。
- **预设注入频率** —— 四档：默认频率、仅首条消息、每条消息、关闭。
- **强制回复语言** —— 自动 / 简体中文 / 英文，只约束模型输出，不翻译你自己的内容。

### 保存项

- **两类条目** —— 片段（可复用文本）与书签（参考链接）。
- **搜索与标签** —— 按关键词搜索，用逗号分隔的标签归类。
- **一键插入对话** —— 直接写进当前 z.ai 对话的输入框。
- **导出备份** —— Markdown 或 JSON。

### 数据管理

- **记忆导入导出** —— 整库备份与恢复。
- **诊断日志导出** —— 导出最近一次会话内后台工具执行与错误信息，用于排查本机工具授权、MCP 连接这类问题。
- **清除全部记忆** —— 一次事务清完，坏数据存在时整份不清（fail-closed）而不是删一半。

### 用量统计

- **总量与分布** —— Token 总量、会话数、消息数。
- **活跃度** —— 活跃天数、当前连续天数、活跃热力图。
- **按天趋势** —— 每天的 Token 走势。
- **按模型分布** —— 各模型的用量与占比，模型名做友好显示。

### 界面

- **中英双语** —— 跟随浏览器、简体中文或 English；界面、工具说明与内置 Skill 行为同步切换。
- **页面背景图** —— 给 z.ai 页面设置自定义背景，支持上传或 URL，可调透明度。
- **主题跟随** —— 注入的 UI 跟随 z.ai 页面的明暗主题，而不是系统主题。
- **工具调用面板** —— 一轮里执行过的工具收成一块可折叠列表，两层折叠，刷新后仍在；可保存 Skill、导入记忆的结果卡片就在里面。
- **历史清洗** —— 刷新会话后，历史里的工具调用标签与续跑模板会被剥除或隐藏，不会把内部结构露给用户。

## 安装

### 安装 Shell Native Host

侧边栏 → **能力** → **MCP** 页会显示一条可复制的安装命令，扩展 ID 已经自动填好：

```bash
npx --yes zai-pp-shell-host install --browser <chrome|edge> --extension-id <你的扩展 ID>
```

`--browser` 取 `chrome`、`edge` 或 `chromium`。需要的环境只有 Node.js ≥ 18.17。

装完**重启浏览器**，回到 MCP 页点「测试」验证连接。

npm 包只是搬运工：`install` 会把 host 运行时拷到你的用户目录，之后删掉全局包也不影响已安装的 host。

常用命令：

```bash
npx --yes zai-pp-shell-host status --browser <chrome|edge>
npx --yes zai-pp-shell-host uninstall --browser <chrome|edge>
```

### 可选：连接 MCP 服务

在 MCP 页新增服务，填传输方式与地址。stdio 类型的服务需要本机已安装对应的命令。
